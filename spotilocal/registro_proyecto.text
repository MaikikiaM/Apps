Hito: Origen de SpotiLocal, Prototipo PWA y Migración a Motor Nativo Capacitor
Compilaciones: #1 (v1.1) a #35 (v1.4.4)
================================================================================
1. CONTEXTO Y PROMPTS INICIALES:
   - Creación de un reproductor de música local offline y de red LAN con estética profesional idéntica a Spotify (modo oscuro, carátulas en alta resolución, tipografía Circular/Inter, controles multimedia).
   - Necesidad de superar las restricciones del navegador móvil (reproducción en segundo plano, control de volumen nativo y lectura de etiquetas ID3 sin servidor central).
2. DECISIONES DE ARQUITECTURA Y LÓGICA:
   - Interfaz Web / PWA (HTML5, CSS modular en styles.css y app.js):
     * Arquitectura cliente-servidor ultraligera con server.js en Node.js para streaming HTTP Range (soporte de 206 Partial Content para seek fluido sin descargar archivos completos).
     * id3-parser.js: parser cliente-side de metadatos ID3v1 y ID3v2 para extraer título, artista, álbum y carátulas incrustadas en formato Blob/ArrayBuffer.
     * audio-engine.js: motor de audio basado en Web Audio API con ecualizador de 5 bandas y analizador en tiempo real para visualizador en Canvas.
   - Migración a Android Nativo (Capacitor):
     * En v1.2.2 (antigua v2.8), se incorporó el puente nativo Capacitor (com.spotilocal.app) para permitir que la app se instale como APK independiente.
     * Creación de NativeAudioStore y NativePlayerBridge para gestionar la caché local de archivos.
3. ARCHIVOS CREADOS / MODIFICADOS:
   - index.html, styles.css, app.js, server.js, audio-engine.js, id3-parser.js
   - apk-build/android/ (Proyecto base Capacitor con Gradle)
